# projeto_matematica_para_analise_de_dados

Projeto para a disciplina Matemática para Análise de Dados. 
Consiste em modificar um código de treinamento de uma rede neural de forma livre. Eu escolhi adicionar uma camada oculta com dois neurônios, e ao invés de usar apenas uma função de ativação (sigmóide), adicionei mais duas: ReLU e tangente hiperbólica.
